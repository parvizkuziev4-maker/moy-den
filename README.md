# Мой День

Личное приложение для iPhone: планнер, трекер привычек, дневник побед и люди с темами для разговора.
Работает без интернета, ставится на экран «Домой». Никакого сервера, регистрации и аналитики.

**Все данные хранятся только на телефоне** (IndexedDB). В этом репозитории — только код приложения.
Резервная копия делается в «Настройки → Резервная копия».

## Установка на iPhone

1. Открой ссылку на приложение в Safari.
2. Нажми «Поделиться» (квадрат со стрелкой).
3. Выбери «На экран Домой». Оставь включённым «Открыть как веб-приложение».
4. Нажми «Добавить» и дальше открывай приложение с иконки.

## Для разработки

```bash
npm install
npm run dev          # http://localhost:5173
npm run dev -- --host  # открыть с iPhone в той же Wi‑Fi сети
npm test             # тесты (Vitest)
npm run build        # сборка в dist/
```

Технологии: Vite, React, TypeScript, Tailwind CSS, Dexie (IndexedDB), vite-plugin-pwa, date-fns, lucide-react.

Публикация: `npm run deploy` — прогоняет тесты, собирает приложение и выкладывает готовые файлы в ветку `gh-pages`
(GitHub Pages). Чтобы публиковать автоматически при каждом push, перенеси `docs/github-actions-deploy.yml`
в `.github/workflows/deploy.yml` (для этого нужен вход `gh auth refresh -s workflow`) и в настройках Pages выбери «GitHub Actions».

### Устройство кода

- `src/db` — база (Dexie), модель данных и операции; миграции описаны в `src/db/db.ts`
- `src/lib` — чистые функции с тестами: серии привычек, повторы задач, обзоры, .ics, резервные копии
- `src/features` — экраны: today, plan, habits, wins, people, stats, settings
- `src/i18n/ru.ts` — все тексты интерфейса
